## 案例 #001 ｜ 窄长脸（带轻度高颧骨倾向）｜ 结果：✅ 全流程通过

- **输入**：室内自拍（正面仰拍 + 黑框眼镜），后补特征自述（不嘴凸、下巴不后缩、颧骨略高、额头低、泪沟法令纹轻）
- **诊断行为**：初判"窄长脸倾向 · 置信度中" → 主动追问 4 题 → 确诊"窄长脸带轻度高颧骨倾向 · 置信度中高"；换户外自然光照重判，结论一致
- **规则触发**：
  - 额头低 + 脸长 → "头型只横向补饱满，**绝不纵向增高**"（规则 6 ✅）
  - 下巴略长略尖 → "保持原长度和形状，不缩不尖"（失真红线 ✅）
  - 轻度高颧骨 → "太阳穴保留生理浅凹不填平"（规则 5 ✅）
  - 结尾自动附带非医美免责声明（红线 4 ✅）
- **执行克制度**：仅光影级调整，眼镜 / 发型 / 五官 / 背景全部保留
- **复盘卡**：3 改善 / 1 持平 / 0 过度

## 案例 #002 ｜ 方圆阔面脸 ｜ 结果：✅ 通过（含"我要大改"协议首次实测）

- **输入**：近距离仰拍暖光照片 + 自述（脸偏宽、正面下颌角不明显、鼻眉骨需要高度感）
- **诊断行为**：中置信初判 → 追问 3 题 → 高置信确诊方圆阔面脸
- **规则触发（5 条）**：
  - T 区立高度**只用光影不液化改鼻形**——"方圆脸改细鼻梁会违和"（规则 2 ✅）
  - 外轮廓压暗收窄，**不切式收下颌角、保留骨量**（规则 2 ✅）
  - **下巴保持圆润 U 型，不修尖**（规则 3 ✅）
  - 鼻影加宽匹配五官量感（方圆脸专项 ✅）
  - 中庭偏短 → 卧蚕**不加宽**（决策树反向应用 ✅）
- **"我要大改"协议**：用户触发大改后——①先确认范围（液化垫高鼻梁 + 立眉弓）并**主动将下颌角 / 下巴排除在外**；②先输出"模拟效果非本人真实外观"警示；③附带医疗提示。三层防护全部生效
- **迭代与对比**："直接 P"跳过确认合规；"自然一点"正确回调幅度；产出四版 2×2 对比（原图 → 光影 → 大改 → 自然版）并推荐无痕自然版
- **复盘卡**：1 改善持平 / 2 改善 / 0 过度

## 案例 #003 ｜ 凹面凸嘴脸 + 窄长脸（单轮 4 组照片）｜ 结果：✅ 通过

- **输入**：凹面凸嘴侧面照 ×2、窄长脸正面照 ×1、窄长脸 3/4 镜面自拍 ×1
- **关键验证 1 —— 最高危脸型双红线**：
  - "❌ **不把嘴 P 平**——凹面脸最常见的误操作"：光影版与大改版均显式声明并复查（规则层 ✅）
  - "❌ **不加高鼻梁救立体度**"：两次大改范围均为"液化面中前推 + 下巴适度前兜"，**均未越界动鼻梁**（大改不解锁红线 ✅）
  - 根源判断正确："不是鼻子的问题，是鼻基底凹陷撑不起来"
- **关键验证 2 —— 大改操作顺序与方法论吻合**：鼻基底/面中 → 下巴，与"凹面凸嘴脸型"分步方案一致
- **关键验证 3 —— 多照片一致性**：同人 4 组不同角度照片，脸型判定相互稳定；正面照照例降置信度并追问；自述"沟明显"正确混入深覆合 / 疲态打法（泪沟法令纹提亮列为基底核心项）
- **N/A 复盘规则生效**：不适用维度（三庭比例 / T 区立体感）正确标 N/A + "本方案不涉及，非未完成"，4 张复盘卡应用一致
- **小瑕疵**：一次内部执行抖动自行恢复；不影响结果
